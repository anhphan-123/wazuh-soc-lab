# SOC Detection & Forensic Investigation Lab

Project cá nhân xây dựng môi trường SOC nhằm thực hành thu thập log,
phát hiện hành vi đáng ngờ và điều tra sự cố bằng Wazuh, Sysmon và
các công cụ phân tích forensic.

## Lab Environment

- Wazuh Server - Ubuntu Server
- Windows 10 Endpoint
- Wazuh Agent
- Sysmon
- REMnux

## Detection Scenarios

1. Registry Run Key Persistence - MITRE ATT&CK T1547.001
2. Suspicious PowerShell Execution
3. SSH Brute Force
4. Suspicious DNS / Network Activity
